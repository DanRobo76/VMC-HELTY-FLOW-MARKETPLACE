# Security Policy

## 🇮🇹 Italiano

### Versioni supportate

| Versione | Home Assistant | Stato |
| --- | :---: | --- |
| Ultima release ([Releases](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/releases)) | 2026.11.0 o successiva | ✅ Riceve le correzioni |
| Release precedenti | – | ❌ Aggiornare all'ultima |

### Segnalare una vulnerabilità

Non aprire una issue pubblica.

1. Aprire [Segnala una vulnerabilità](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/security/advisories/new).
2. Indicare la versione dell'integrazione e di Home Assistant.
3. Descrivere il problema e i passi per riprodurlo.

La segnalazione resta privata fino alla correzione.

Prima risposta entro 7 giorni.

Gli errori che non riguardano la sicurezza vanno nelle [Issues](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/issues).

## 🇺🇸 English

### Supported versions

| Version | Home Assistant | Status |
| --- | :---: | --- |
| Latest release ([Releases](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/releases)) | 2026.11.0 or later | ✅ Receives fixes |
| Older releases | – | ❌ Update to the latest |

### Reporting a vulnerability

Do not open a public issue.

1. Open [Report a vulnerability](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/security/advisories/new).
2. State the integration and Home Assistant versions.
3. Describe the problem and the steps to reproduce it.

The report stays private until it is fixed.

First answer within 7 days.

Bugs that are not about security go to the [Issues](https://github.com/DanRobo76/VMC-HELTY-FLOW-MARKETPLACE/issues).
